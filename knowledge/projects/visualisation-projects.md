# Data visualisation and analysis portfolio

## Dear Abby

Visualises trends in questions sent to the Dear Abby column over the years. Brenda explored the data in Python (Jupyter), merged the date fields into a timeline, summarised the questions, clustered similar topics and visualised the result with D3.js. Goal: show how the topics people asked about changed over time.

## DASS (Depression Anxiety Stress Scale)

Analysis of 2018 open-psychometrics responses to the Depression Anxiety Stress Scale. Methods: inferential statistics, data exploration, data modeling and data visualisation. Goal: present data about these "silent" conditions in a way that is engaging for people affected, so they can recognise when to ask for help.

## Hitch-Hiker's Travel Guide

Analysis of Numbeo crowd-sourced cost-of-living data (housing, crime, healthcare, transport) to help hitch-hikers and holiday makers make better financial decisions when travelling.

## Build Up Nepal (Viz for Social Good)

A Tableau dashboard for the Viz for Social Good project with Build Up Nepal, published on Tableau Public.

## Zines

Data tutorials drawn as quick sketches, for example how to start a project and how data modeling works.
