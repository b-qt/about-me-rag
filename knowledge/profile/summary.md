# Professional profile

Quinsy Brenda Tebid ("Brenda") is a Data & Analytics Engineer based in Spain, originally from Cameroon. She holds 2 Master's in Big Data and Analytics and a second in Web design and development from Harbour Space Institute (Barcelona) and a BSc in Information Technology with a minor in Software Engineering from ICT University (Yaoundé).

## Summary

Technical Data Analyst and Analytics Engineer with a Master's in Big Data. Expert in end-to-end analytics: from building ingestion pipelines in Python and SQL to designing complex Looker dashboards. Proven track record of translating business needs into data models that drive decision-making.

## Technical skills

- Data science and analysis: Python (Pandas, Apache Arrow, Scikit-learn), statistical modeling, A/B testing, data modeling, business logic.
- Data engineering and pipelines: SQL (PostgreSQL) for complex queries, performance tuning and data modeling; ETL principles, with extensive experience designing, building and maintaining end-to-end data pipelines; data warehousing (BigQuery).
- Cloud platforms: AWS (S3, Lambda), GCP (BigQuery), Azure.
- Orchestration and DevOps: Linux, dimensional modeling, MageAI, Apache Airflow, dbt, Docker, Git.
- BI and visualisation: Tableau, Power BI, Looker, D3.js, ArcGIS.
