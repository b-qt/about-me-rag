# TARGET ROLE (job posting, NOT past work): Open Earth Foundation, Platform Data Engineer

## The role

Design and build the shared data platform behind a global climate-data reporting and analysis service for cities. Cities use it to report emissions and climate risks, plan actions and track progress. Several applications (inventory, risk assessment, planning, reporting, monitoring) run on one data infrastructure: a warehouse that receives data from thousands of cities plus the pipeline platform that feeds it. Mid-level role, shipping substantial pieces of the platform with a manager.

## Duties

- Design and evolve the analytical warehouse (raw, modelled and reporting layers) with schemas published as contracts.
- Model complex relational and analytical data in PostgreSQL, including geospatial data in PostGIS: boundaries, activity data, indicators and record history.
- Build reusable pipeline patterns for ingestion, transformation, tests, versioning and lineage.
- Keep operational databases separate from the analytical warehouse; define stable interfaces to the warehouse.
- Set data-quality checks, observability and reproducibility so every number traces back to its dataset version.
- Partner with the Mitigation Data Engineer and software engineers; deploy pipelines on cloud infrastructure; use AI tools and review their output; document models and conventions.

## Qualifications

- 3 years in data engineering or a closely related role.
- Strong SQL and data modeling (designed schemas others build on); strong Python.
- PostgreSQL as an analytical store, or a cloud warehouse (BigQuery, Snowflake, Redshift).
- At least one transformation or orchestration tool (dbt, Airflow, Dagster, Mage or similar).
- A cloud platform (AWS, GCP or Azure).
- Built pipelines or a data platform used by more than one application or team.
- Nice to have: PostGIS or other geospatial tooling.
