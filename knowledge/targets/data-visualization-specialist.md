# TARGET ROLE (job posting, NOT past work): Data Visualization Specialist (remote, work from anywhere)

An agency posting for a client in the data infrastructure and analytics industry, seeking a subject-matter expert in chart and data-visualisation analysis, full time.

## Duties

- Analyse and interpret chart patterns, data trends and visualisation outputs to find key insights.
- Work with stakeholders to refine data representations and improve clarity.
- Write documentation for chart and visualisation standards and best practices.
- Advise on visualisation techniques to improve the accuracy and usability of reports.

## Requirements

- Tableau, Power BI or similar.
- Strong analytical skills; clear, actionable charts; data modeling and visualisation best practice.
- Communicating technical insights to non-technical stakeholders; statistical analysis.
- SQL is a plus.
